# Concept: WHEEL
# Definition
FLAT CIRCULAR TOOL WHICH CAN ROLL.
# Criteria and general notes
## Huang Jingui
HUANG JINGUI 2006
COMM 7.
輇（ quan ），最早的車輪，沒有輻條，輪徑較短。又稱 “ 椎輪 ” ，有古樸色彩。
輪，有輻條之輪；車輪總稱。
軌，兩輪間空間；也稱轉動的輪。
轔，行車聲；也可代稱車輪，多作動詞，為輪壓義。
